# 数据库表字段说明

## 1. 文档维护规则

- 本文件记录当前已经通过 Prisma 迁移创建的数据库表和字段。
- 后续只要 `apps/server/prisma/schema.prisma` 新增、删除或调整表字段，必须同步更新本文件。
- 本文件面向开发理解和数据排查，字段口径以 `schema.prisma` 和对应迁移文件为准。
- 当前数据库保存用户主信息、用户配置、房间、房间成员、对局主记录、对局玩家关系、动作日志、快照、结果和统计。
- 运行中完整牌面状态仍由服务端内存仓库承载，数据库快照用于内存缺失时恢复兜底。

## 3. User 用户主表

用途：

- 保存玩家账号或本地访客用户的基础展示信息。
- 登录注册会写入真实账号资料。
- 当前创建对局时仍会按 `currentPlayerId` 补齐历史本地用户或机器人用户，但不会覆盖已注册用户昵称。

| 字段名         | Prisma 类型    | 数据库约束 / 默认值 | 是否可空 | 字段说明                                           |
| -------------- | -------------- | ------------------- | -------- | -------------------------------------------------- |
| `id`           | `String`       | 主键，默认 `uuid()` | 否       | 用户唯一标识。                                     |
| `username`     | `String?`      | 唯一索引            | 是       | 登录账号，历史本地用户和机器人用户允许为空。       |
| `passwordHash` | `String?`      | 无                  | 是       | 登录密码摘要，只能服务端写入，禁止返回前端。       |
| `nickname`     | `String`       | 无                  | 否       | 用户昵称，用于个人页、房间和对局内展示。           |
| `avatarUrl`    | `String?`      | 无                  | 是       | 用户头像地址，未配置时由前端展示默认头像。         |
| `status`       | `String`       | 默认 `"ACTIVE"`     | 否       | 用户账号状态，当前先用字符串保留后续枚举扩展空间。 |
| `createdAt`    | `DateTime`     | 默认 `now()`        | 否       | 用户记录创建时间，由数据库写入。                   |
| `updatedAt`    | `DateTime`     | `@updatedAt`        | 否       | 用户记录更新时间，每次更新时由 Prisma 自动刷新。   |
| `setting`      | `UserSetting?` | 一对一关系字段      | 是       | 用户个人配置关系字段，不是独立数据库列。           |
| `sessions`     | `Session[]`    | 一对多关系字段      | 否       | 用户登录会话列表，不是独立数据库列。               |
| `games`        | `GamePlayer[]` | 一对多关系字段      | 否       | 用户参与过的对局关系，不是独立数据库列。           |
| `ownedRooms`   | `Room[]`       | 一对多关系字段      | 否       | 用户创建的房间列表，不是独立数据库列。             |
| `roomPlayers`  | `RoomPlayer[]` | 一对多关系字段      | 否       | 用户加入过的房间成员关系，不是独立数据库列。       |
| `wonResults`   | `GameResult[]` | 一对多关系字段      | 否       | 用户作为第一名的对局结果，不是独立数据库列。       |
| `stat`         | `PlayerStat?`  | 一对一关系字段      | 是       | 用户长期统计，不是独立数据库列。                   |

关系：

- `User.setting` 与 `UserSetting.user` 是一对一关系。
- `User.sessions` 与 `Session.user` 是一对多关系。
- `User.games` 与 `GamePlayer.user` 是一对多关系。
- `User.ownedRooms` 与 `Room.owner` 是一对多关系。
- `User.roomPlayers` 与 `RoomPlayer.user` 是一对多关系。
- `User.wonResults` 与 `GameResult.winner` 是一对多关系。
- `User.stat` 与 `PlayerStat.user` 是一对一关系。
- 删除 `User` 时，对应 `UserSetting` 会通过外键级联删除。
- 删除 `User` 时，对应 `Session` 会通过外键级联删除。
- 删除 `User` 时，对应 `GamePlayer` 会通过外键级联删除。

## 4. Session 用户会话表

用途：

- 保存登录会话的 token 摘要和过期时间。
- 明文 token 只在注册或登录响应中返回一次，数据库不保存明文 token。

| 字段名      | Prisma 类型 | 数据库约束 / 默认值           | 是否可空 | 字段说明                         |
| ----------- | ----------- | ----------------------------- | -------- | -------------------------------- |
| `id`        | `String`    | 主键，默认 `uuid()`           | 否       | 会话唯一标识。                   |
| `userId`    | `String`    | 外键关联 `User.id`            | 否       | 用户唯一标识。                   |
| `tokenHash` | `String`    | 唯一索引                      | 否       | 会话令牌摘要，用于服务端查会话。 |
| `expiresAt` | `DateTime`  | 无                            | 否       | 会话过期时间。                   |
| `createdAt` | `DateTime`  | 默认 `now()`                  | 否       | 会话创建时间。                   |
| `user`      | `User`      | 关系字段，`onDelete: Cascade` | 否       | 会话归属用户，不是独立数据库列。 |

索引和约束：

- `tokenHash` 唯一索引：保证同一 token 摘要只对应一个会话。
- `@@index([userId])`：方便查询用户会话。
- `@@index([expiresAt])`：方便后续清理过期会话。

## 5. Game 对局主表

用途：

- 保存一局游戏的基础生命周期信息。
- 当前只记录对局是否进行中、当前阶段和版本号，不存玩家手牌、牌堆、桌面牌等完整运行态。
- 完整权威对局状态当前仍在服务端内存仓库中。

| 字段名         | Prisma 类型      | 数据库约束 / 默认值        | 是否可空 | 字段说明                                                  |
| -------------- | ---------------- | -------------------------- | -------- | --------------------------------------------------------- |
| `id`           | `String`         | 主键，由后端创建对局时生成 | 否       | 对局唯一标识。                                            |
| `roomId`       | `String?`        | 无                         | 是       | 房间标识，当前房间体系未接入时为空。                      |
| `mode`         | `String`         | 默认 `normal`              | 否       | 对局模式，当前支持普通模式和单人人机模式。                |
| `status`       | `String`         | 无                         | 否       | 对局生命周期状态，例如当前代码使用 `ACTIVE`、`FINISHED`。 |
| `currentPhase` | `String`         | 无                         | 否       | 当前对局阶段，对应游戏核心状态机中的阶段值。              |
| `stateVersion` | `Int`            | 默认 `0`                   | 否       | 对局状态版本号，用于动作并发控制、快照和动作幂等。        |
| `finishReason` | `String?`        | 无                         | 是       | 对局结束原因，正常结束、退出或重新开始时写入。            |
| `startedAt`    | `DateTime`       | 默认 `now()`               | 否       | 对局开始时间。                                            |
| `finishedAt`   | `DateTime?`      | 无                         | 是       | 对局结束时间，未结束时为空。                              |
| `createdAt`    | `DateTime`       | 默认 `now()`               | 否       | 对局主记录创建时间。                                      |
| `updatedAt`    | `DateTime`       | `@updatedAt`               | 否       | 对局主记录更新时间，每次更新时由 Prisma 自动刷新。        |
| `players`      | `GamePlayer[]`   | 一对多关系字段             | 否       | 对局玩家关系，不是独立数据库列。                          |
| `room`         | `Room?`          | 可选关系字段               | 是       | 对局所属房间，不是独立数据库列。                          |
| `actions`      | `GameAction[]`   | 一对多关系字段             | 否       | 对局动作日志，不是独立数据库列。                          |
| `snapshots`    | `GameSnapshot[]` | 一对多关系字段             | 否       | 对局快照，不是独立数据库列。                              |
| `result`       | `GameResult?`    | 一对一关系字段             | 是       | 对局最终结果，不是独立数据库列。                          |

当前限制：

- 不保存完整 `GameState`。
- 完整 `GameState` 通过 `GameSnapshot.stateJson` 以 JSON 快照保存。
- 当前支持内存缺失时按需从最新快照恢复。

## 6. GamePlayer 对局玩家关系表

用途：

- 保存一局对局中每个座位对应的用户。
- 区分真人玩家和机器人玩家。
- 保存玩家最终名次和完成时间，为后续对局记录、个人战绩、机器人账号化打基础。

| 字段名       | Prisma 类型 | 数据库约束 / 默认值           | 是否可空 | 字段说明                                               |
| ------------ | ----------- | ----------------------------- | -------- | ------------------------------------------------------ |
| `id`         | `String`    | 主键，默认 `uuid()`           | 否       | 对局玩家关系唯一标识。                                 |
| `gameId`     | `String`    | 外键关联 `Game.id`            | 否       | 对局唯一标识。                                         |
| `userId`     | `String`    | 外键关联 `User.id`            | 否       | 用户唯一标识，当前单机阶段真人和机器人都会写入用户表。 |
| `seat`       | `Int`       | 与 `gameId` 组成唯一约束      | 否       | 对局内座位序号。                                       |
| `playerType` | `String`    | 无                            | 否       | 玩家类型，当前使用 `human` 或 `bot`。                  |
| `finalRank`  | `Int?`      | 无                            | 是       | 最终名次，玩家尚未完成时为空。                         |
| `finishedAt` | `DateTime?` | 无                            | 是       | 玩家出完手牌并产生名次的时间，未完成时为空。           |
| `createdAt`  | `DateTime`  | 默认 `now()`                  | 否       | 对局玩家关系创建时间。                                 |
| `updatedAt`  | `DateTime`  | `@updatedAt`                  | 否       | 对局玩家关系更新时间，每次更新时由 Prisma 自动刷新。   |
| `game`       | `Game`      | 关系字段，`onDelete: Cascade` | 否       | 关系所属对局，不是独立数据库列。                       |
| `user`       | `User`      | 关系字段，`onDelete: Cascade` | 否       | 关系所属用户，不是独立数据库列。                       |

索引和约束：

- `@@unique([gameId, seat])`：保证同一局内一个座位只有一名玩家。
- `@@unique([gameId, userId])`：保证同一局内同一用户不重复入局。
- `@@index([userId])`：方便后续查询某个用户参与过的对局。

关系：

- `GamePlayer.gameId` 关联 `Game.id`。
- `GamePlayer.userId` 关联 `User.id`。
- 删除 `Game` 时，该局玩家关系会级联删除。
- 删除 `User` 时，该用户的对局关系会级联删除。

当前写入时机：

- `POST /games` 创建对局时同步写入所有玩家座位关系。
- 玩家产生名次后，后端更新对局主记录时同步写入 `finalRank` 和 `finishedAt`。

## 7. UserSetting 用户个人配置表

用途：

- 保存用户可长期保留的个人偏好。
- 当前已支持读取和局部更新配置接口。
- 本表只保存配置，不参与游戏规则判断。

| 字段名             | Prisma 类型 | 数据库约束 / 默认值           | 是否可空 | 字段说明                                               |
| ------------------ | ----------- | ----------------------------- | -------- | ------------------------------------------------------ |
| `id`               | `String`    | 主键，默认 `uuid()`           | 否       | 配置唯一标识。                                         |
| `userId`           | `String`    | 唯一索引，外键关联 `User.id`  | 否       | 用户唯一标识，一名用户只允许拥有一条配置。             |
| `autoSortEnabled`  | `Boolean`   | 默认 `false`                  | 否       | 是否开启手牌自动排序，后续个人页可切换。               |
| `botLevel`         | `String`    | 默认 `"NORMAL"`               | 否       | 默认机器人等级，当前只保存配置值，暂不改变机器人策略。 |
| `soundEnabled`     | `Boolean`   | 默认 `true`                   | 否       | 是否开启对局音效，当前预留给后续画面优化阶段。         |
| `animationEnabled` | `Boolean`   | 默认 `true`                   | 否       | 是否开启动画效果，当前预留给后续画面优化阶段。         |
| `showEventPanel`   | `Boolean`   | 默认 `true`                   | 否       | 是否显示事件栏，当前预留给后续个人页配置。             |
| `createdAt`        | `DateTime`  | 默认 `now()`                  | 否       | 配置记录创建时间。                                     |
| `updatedAt`        | `DateTime`  | `@updatedAt`                  | 否       | 配置记录更新时间，每次更新时由 Prisma 自动刷新。       |
| `user`             | `User`      | 关系字段，`onDelete: Cascade` | 否       | 配置归属用户，不是独立数据库列。                       |

关系：

- `UserSetting.userId` 关联 `User.id`。
- `userId` 有唯一约束，保证一个用户只有一条配置。
- 删除用户时，该用户配置会级联删除。

## 12. GameResult 对局结果表

用途：

- 保存一局游戏结束后的结果摘要。
- 对局第一次进入 `GAME_OVER` 时写入。

| 字段名         | Prisma 类型 | 数据库约束 / 默认值           | 是否可空 | 字段说明                         |
| -------------- | ----------- | ----------------------------- | -------- | -------------------------------- |
| `id`           | `String`    | 主键，默认 `uuid()`           | 否       | 结果唯一标识。                   |
| `gameId`       | `String`    | 唯一索引，外键关联 `Game.id`  | 否       | 对局唯一标识。                   |
| `winnerUserId` | `String?`   | 外键关联 `User.id`，普通索引  | 是       | 第一名用户标识。                 |
| `rankingsJson` | `Json`      | 无                            | 否       | 完整排名 JSON。                  |
| `scoreJson`    | `Json?`     | 无                            | 是       | 计分 JSON，当前预留为空对象。    |
| `createdAt`    | `DateTime`  | 默认 `now()`                  | 否       | 结果创建时间。                   |
| `game`         | `Game`      | 关系字段，`onDelete: Cascade` | 否       | 结果所属对局，不是独立数据库列。 |
| `winner`       | `User?`     | 关系字段，`onDelete: SetNull` | 是       | 第一名用户，不是独立数据库列。   |

## 13. PlayerStat 玩家统计表

用途：

- 保存用户长期对局数量、胜场和平均名次。
- 对局第一次写入结果时增量更新。

| 字段名        | Prisma 类型 | 数据库约束 / 默认值           | 是否可空 | 字段说明                         |
| ------------- | ----------- | ----------------------------- | -------- | -------------------------------- |
| `id`          | `String`    | 主键，默认 `uuid()`           | 否       | 统计唯一标识。                   |
| `userId`      | `String`    | 唯一索引，外键关联 `User.id`  | 否       | 用户唯一标识。                   |
| `totalGames`  | `Int`       | 默认 `0`                      | 否       | 总对局数。                       |
| `winGames`    | `Int`       | 默认 `0`                      | 否       | 第一名次数。                     |
| `averageRank` | `Float`     | 默认 `0`                      | 否       | 平均名次。                       |
| `lastGameAt`  | `DateTime?` | 无                            | 是       | 最近完成对局时间。               |
| `updatedAt`   | `DateTime`  | `@updatedAt`                  | 否       | 统计更新时间。                   |
| `user`        | `User`      | 关系字段，`onDelete: Cascade` | 否       | 统计所属用户，不是独立数据库列。 |

## 14. 当前接口对应关系

| 接口                          | 涉及表                                                                           | 说明                                                                                                                                 |
| ----------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `POST /auth/register`         | `User`、`Session`                                                                | 创建用户账号、保存密码摘要并写入登录会话。                                                                                           |
| `POST /auth/login`            | `User`、`Session`                                                                | 校验账号密码，成功后写入登录会话。                                                                                                   |
| `GET /auth/me`                | `Session`、`User`                                                                | 按 Bearer token 摘要查询当前用户。                                                                                                   |
| `POST /auth/logout`           | `Session`                                                                        | 删除当前登录会话。                                                                                                                   |
| `POST /games`                 | `User`、`Game`、`GamePlayer`、`GameSnapshot`、`GameAction`                       | 创建对局时补齐本地用户和机器人用户，并在同一事务内写入对局主记录、玩家关系、初始快照和开局日志。                                     |
| `POST /games/:gameId/actions` | `Game`、`GameAction`、`GameSnapshot`、`GamePlayer`、`GameResult`、`PlayerStat`   | 提交玩家动作，使用 `stateVersion` 校验版本，使用 `clientActionId` 避免重复执行；成功动作会在同一事务内写入对局版本、快照和动作日志。 |
| `POST /games/:gameId/finish`  | `Game`、`GameSnapshot`、`GameAction`                                             | 人机模式主动退出或重新开始时，将旧局标记为已结束并写入结束原因，不写入正常胜负结果和战绩统计。                                       |
| `GET /records/games`          | `Game`、`GamePlayer`                                                             | 查询最近对局主记录，传入 `userId` 时只返回该用户参与过的对局。                                                                       |
| `GET /users/:userId/settings` | `User`、`UserSetting`                                                            | 查询用户配置；首次查询时会补齐默认用户和默认配置。                                                                                   |
| `PUT /users/:userId/settings` | `User`、`UserSetting`                                                            | 局部更新用户配置，未传字段保持当前值或默认值。                                                                                       |
| `GET /games/:gameId/actions`  | `GameAction`                                                                     | 查询指定对局动作日志。                                                                                                               |
| `GET /games/:gameId/result`   | `GameResult`                                                                     | 查询指定对局最终结果。                                                                                                               |
| `POST /rooms`                 | `User`、`Room`、`RoomPlayer`                                                     | 创建房间并加入房主。                                                                                                                 |
| `GET /rooms/:roomId`          | `Room`、`RoomPlayer`                                                             | 查询房间快照。                                                                                                                       |
| `POST /rooms/:roomId/join`    | `User`、`RoomPlayer`                                                             | 加入房间或恢复在线状态。                                                                                                             |
| `POST /rooms/:roomId/leave`   | `RoomPlayer`                                                                     | 离开房间并标记离线。                                                                                                                 |
| `POST /rooms/:roomId/ready`   | `RoomPlayer`                                                                     | 更新准备状态。                                                                                                                       |
| `POST /rooms/:roomId/start`   | `Room`、`RoomPlayer`、`User`、`Game`、`GamePlayer`、`GameSnapshot`、`GameAction` | 房主从房间开始对局，写入真实 `Game.roomId` 并生成对局初始快照和日志。                                                                |
| `POST /rooms/:roomId/close`   | `Room`                                                                           | 关闭房间。                                                                                                                           |
| `GET /users/:userId/stats`    | `PlayerStat`                                                                     | 查询用户战绩统计。                                                                                                                   |
| `GET /records/player-stats`   | `PlayerStat`                                                                     | 查询玩家统计排行。                                                                                                                   |
