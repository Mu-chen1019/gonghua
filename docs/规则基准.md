# 规则基准

本项目首版规则范围以旧项目已完成的第二至第四阶段为准：牌堆生成、洗牌发牌、翻主牌、首攻判定、基础攻防、同点加攻、大小王封攻、守牌撤回、守牌换位、放弃防守和等待中途添牌状态。

## 首版不实现

- 实际中途添牌
- 轮后添牌
- 下轮轮转
- 全局排名
- 真实联机
- 数据库持久化

## 关键约束

- 前端只展示玩家可见视角，不保存完整对局状态。
- 后端保存完整对局状态，是动作提交和规则校验的权威来源。
- `packages/game-core` 保持纯函数，不依赖前端、后端框架和数据库。
- 牌堆底部主牌仍属于牌堆，不作为第五个状态区域。
- 每张牌同一时间只能属于一个区域：玩家手牌、牌堆、桌面区、弃牌区。
