# 攻花 H5 项目画面优化阶段步骤

## 1. 文档目标

- 本文档承接 `docs/step/开发阶段step.md` 后续工作，只记录主页、个人页和移动端横屏通用页面体验。
- 对局内游戏画面、游戏内交互、手牌样式、玩家形象和背景设计放在 `docs/step/游戏界面step.md`。
- 功能结构优化、联机预留和代码收口放在 `docs/step/功能优化step.md`。
- 发布上线、渠道和运营工作拆分到 `docs/step/发布上线step.md`。
- 后续开发仍默认遵守根目录 `AGENTS.md`，规则口径优先参考 `docs/rules.md`。

## 2. 阶段 1：对局页与移动端横屏收口

目标：保证 H5 在 PC 和移动端横屏都可玩。

任务：

- 建立页面级布局分离：PC 完整布局、移动横屏精简布局。
- 环境判断只放在页面入口或布局选择层。
- 移动横屏优先展示桌面牌区、当前玩家手牌、操作按钮、关键状态条。
- 隐藏或收起非关键日志、说明、装饰和次要面板。
- 保证按钮可点、手牌可滚动、桌面牌位不重叠。
- 保留当前机器人手牌展示能力，移动端可压缩或收起，但不能影响真人出牌和守牌主流程。

完成标准：

- PC 布局信息完整。
- 移动横屏布局对局核心元素清晰可操作。
- 新增功能时不需要在业务逻辑中散落布局判断。

测试重点：

- PC、移动竖屏、移动横屏的基本布局。
- 关键按钮不会被遮挡。
- 手牌横向滚动可用。
- 桌面牌位和事件提示不重叠。
- 机器人手牌溢出时只在自身区域滚动，不撑破玩家面板。

## 3. 阶段 2：主页功能实现

目标：让主页承担真实入口职责，而不是只作为占位页面。

任务：

- 设计主页信息结构：
    - 快速开始单机对局。
    - 创建联机房间入口。
    - 加入房间入口。
    - 最近对局入口。
    - [x] 首页已接入最近未结束对局入口，可直接继续进入原对局。
    - [x] 首页最近对局已按当前登录用户筛选。
    - 规则说明入口。
    - 个人页入口。
- 快速开始支持基础配置：
    - 玩家人数。
    - [x] 大厅创建房间已支持选择 2-6 人。
    - 机器人数量。
    - 机器人等级。
    - 是否显示机器人手牌。
    - 是否开启自动排序。
- 创建对局前做表单校验，错误提示使用非阻塞提醒，不打断用户。
- 增加最近一次对局恢复入口，对局不存在时仍自动回首页。
- 首页视觉以实际游戏入口为第一屏，不做纯营销落地页。
- 首页按钮和入口在移动端横屏可直接点击，不被顶部或底部区域遮挡。

完成标准：

- 用户进入应用后能直接开始对局或进入房间。
- 首页配置项与后端创建对局参数保持一致，不单边造字段。
- 首页在 PC、移动竖屏、移动横屏下都能正常操作。

测试重点：

- 快速开始能成功创建对局并进入对局页。
- 非法配置会给出明确提醒。
- 最近对局不存在时能回退到首页正常状态。
- [x] 大厅页已接入创建房间、查询房间、加入测试玩家、准备和开始对局的基础操作。
- [x] 大厅页已拆分人机对局、创建联机房间和加入联机房间入口，支持展示和复制房间号。

## 4. 阶段 3：个人页面功能实现

目标：个人页承载用户偏好、对局记录和后续账号能力。

任务：

- 实现个人资料展示：
    - [x] 昵称。
    - 头像占位或头像上传预留。
    - [x] 用户标识。
    - 创建时间或本地首次进入时间。
- [x] 新增简单登录注册页，用于建立当前用户身份。
- 实现对局偏好配置：
    - 是否默认开启自动排序。
    - 机器人默认等级。
    - 是否展示机器人完整手牌。
    - 机器人操作延迟。
    - 事件栏默认展开或收起。
    - 牌面大小偏好。
- 实现对局记录入口：
    - 最近对局。
    - 对局结果。
    - 名次。
    - 对局时间。
    - 是否可继续。
- 实现基础战绩统计：
    - 总局数。
    - 第一名次数。
    - 平均名次。
    - 最近胜负走势。
- 单机阶段先支持本地存储，联机阶段再接后端用户数据。
- 个人页配置要通过统一 store 或 service 消费，避免散落在页面组件中。

完成标准：

- 用户可以在个人页修改基础偏好，并影响新创建的对局体验。
- 页面刷新后个人偏好仍能恢复。
- 后续接登录或数据库时，不需要重写页面主体结构。

测试重点：

- 修改自动排序配置后，新对局默认值正确。
- 修改机器人展示配置后，对局页展示行为正确。
- 本地记录为空时有正常空状态。

## 5. 阶段 4：整体视觉与交互细节

目标：让当前单机可玩版本从“能用”提升到“顺手、清晰、稳定”。

任务：

- 统一卡牌、按钮、面板、事件栏、状态条的视觉层级。
- 优化牌桌布局，确保攻牌和守牌关系一眼可读。
- 优化拖拽反馈：
    - 可投放区域高亮。
    - 非法投放回弹。
    - 动作失败非阻塞提醒。
    - 拖动过程中不遮挡关键牌面。
- 优化事件栏：
    - 新事件在顶部。
    - 主谓宾完整。
    - 支持按系统、玩家、机器人、错误筛选的预留结构。
- 优化只出不添、排名和对局结束展示。
- 增加桌面密集牌位的自适应缩放，避免小屏重叠。
- 增加基础无障碍能力：按钮语义、可点击区域、焦点状态和颜色对比。

完成标准：

- 对局关键状态不用阅读说明也能判断。
- 鼠标、触屏拖拽都能顺畅完成出牌和守牌。
- 小屏横屏下不出现核心元素遮挡。

测试重点：

- PC 和移动横屏截图检查。
- 拖拽出攻牌、拖拽守牌、拖拽换守牌路径可用。
- 提醒、事件、排名和结束状态展示不互相遮挡。
